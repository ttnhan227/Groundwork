# Groundwork audit — 8 October 2026

Scope: current local implementation of the desktop reader, file evidence and extraction, organization controls, application navigation, settings, backend suites, website and build/release checks. This is a regression audit, not a guarantee that every format, button and Windows environment is defect-free.

## Defects corrected

- File requests with a caller cancellation signal now retain the 15-second request timeout. Mutation timeouts advise checking completion before retrying.
- The hidden file workspace no longer handles reader keyboard shortcuts. Reader F5 reloads the document; Alt+Left returns to the existing folder without changing its history behind the reader.
- Failed settings information loads show an error and a retry control rather than remaining in an opening state. Refresh and restart have synchronous duplicate-submission guards.
- Organization preference and rule saves reject rapid repeated submissions. Save/delete errors appear inside the relevant dialog; dialogs cannot close during those writes. Rule execution and guided-example creation use the same operation guard.
- Document archives have a 10,000-entry processing limit and reuse an entry-name set. Rejected or damaged document extraction returns an unsupported-content explanation; invalid page requests remain explicit errors. The archive limit applies after ZIP metadata is opened and does not constitute a complete resource-exhaustion defense.
- Outdated onboarding, website navigation and document-coverage assertions now match the current interface. Desktop reader regression checks and website interaction checks are included in CI; release validation also runs reader checks.

## Remaining limits and release implications

- This audit did not rebuild/install a fresh Windows installer or repeat upgrade/recovery tests against a newly packaged binary. Current local changes are not yet published downloads.
- Office viewing displays extracted text, not original page layout. PDF viewing is rendered pages; it is not a full PDF editor. OCR recognizes written text and is not image-scene understanding or a complete background OCR search index.
- Large documents and folder evidence are intentionally bounded. Unsupported content falls back to metadata; the assistant must not imply it read unavailable content. Local-model answer quality and latency still vary with the question and hardware.
- Controlled UI tests cannot establish that every installed application, unusual permission state, file format or real-world workflow works. Fresh installed-app validation and live account/sync validation remain separate checks.
- Several desktop components, particularly organization, still combine presentation with asynchronous workflow coordination. Focused regression tests reduce risk, but the code remains a maintenance concern; avoid a broad refactor alongside these fixes.

No version bump, commit, push, deployment or release replacement was performed during this audit.
